# Nexus Backend

Production-grade Express + TypeScript backend.

## Getting Started

### Prerequisites
- Node.js (>= 22.11.0)
- Yarn

### Installation
```bash
yarn install
```

### Development
```bash
yarn dev
```

### Build
```bash
yarn build
```

### Testing
```bash
yarn test
```

## API Documentation
Once the server is running, visit:
- Health Check: `http://localhost:3000/api/health`
- Swagger Docs: `http://localhost:3000/api-docs` (Coming soon)
